## Composants & Object IDs

#### `OBJ-22-1` — Header
| Propriété | Valeur |
|-----------|--------|
| **Type** | Titre `h1` + bouton "Modifier" |
| **Token** | `heading-md` (20px), poids 600 |

#### `OBJ-22-2` — Avatar + identité
| Propriété | Valeur |
|-----------|--------|
| **Type** | Avatar (initiales ou photo) + nom + email |
| **Avatar** | Cercle avec initiales couleur principale (si pas de photo) |
| **Token nom** | `heading-lg` (24px), poids 700 |

#### `OBJ-22-3` — Informations compte
| Propriété | Valeur |
|-----------|--------|
| **Type** | Liste de champs (lecture/édition) |
| **Champs** | Nom complet / Email / Téléphone (optionnel) / Revenus mensuels / Situation familiale |
| **Mode** | Lecture par défaut, édition si bouton "Modifier" |

#### `OBJ-22-4` — Navigation profil
| Propriété | Valeur |
|-----------|--------|
| **Type** | Liste de liens avec chevrons |
| **Items** | Paramètres & intégrations / Mon abonnement / Confidentialité / Aide |

#### `OBJ-22-5` — Bouton déconnexion
| Propriété | Valeur |
|-----------|--------|
| **Type** | Button destructif |
| **Token** | `heading-xs` (16px), poids 500 |
| **Couleur** | Rouge |
