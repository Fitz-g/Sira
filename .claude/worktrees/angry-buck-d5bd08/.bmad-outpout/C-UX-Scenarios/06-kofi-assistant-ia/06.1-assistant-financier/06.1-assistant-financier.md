## État mental

**Curieux et en attente.** Kofi a une question précise. Il veut une réponse adaptée à SA situation — pas une réponse générique qu'il aurait pu trouver sur Google.

- **Espoir :** "Il connaît mon profil, il va me donner le bon conseil."
- **Crainte :** "Et si c'est juste un chatbot générique qui répond n'importe quoi ?"

**→ Implication design :** Contexte profil visible en haut (prouve que l'IA "sait"), suggestions de questions rapides, réponses concises avec chiffres réels du profil.

## Composants & Object IDs

#### `OBJ-18-1` — Header
| Propriété | Valeur |
|-----------|--------|
| **Type** | Titre `h1` + icône assistant |
| **Token** | `heading-md` (20px), poids 600 |

#### `OBJ-18-2` — Bande contexte profil
| Propriété | Valeur |
|-----------|--------|
| **Type** | Card compacte |
| **Contenu** | Résumé profil dynamique : "Je connais ta situation : [revenus], [dettes], [objectif]" |
| **Style** | Fond teinté couleur principale (léger), icône cerveau/profil |
| **Objectif** | Montrer que l'IA a de la mémoire — différenciateur clé |

#### `OBJ-18-3` — Zone de conversation
| Propriété | Valeur |
|-----------|--------|
| **Type** | Chat interface scrollable |
| **Bulles user** | Droite, couleur principale |
| **Bulles IA** | Gauche, fond neutre |
| **Message initial** | Message de bienvenue de l'assistant avec son prénom |

#### `OBJ-18-4` — Chips suggestions rapides
| Propriété | Valeur |
|-----------|--------|
| **Type** | Chips horizontaux scrollables |
| **Contenu** | Questions fréquentes pré-définies (dynamiques selon profil) |
| **Exemples** | "Dois-je rembourser ma dette ou épargner ?", "Comment réduire mes dépenses ?" |

#### `OBJ-18-5` — Input message
| Propriété | Valeur |
|-----------|--------|
| **Type** | Text input + bouton envoyer |
| **Placeholder** | "Pose ta question..." |
| **Bouton** | Icône envoyer (flèche), activé si input non vide |
