# Dialog Log — Step 10: Contraintes

## Paramètres de design du projet

| Catégorie | Contrainte | Flexibilité |
|-----------|-----------|-------------|
| **Timeline** | Pas de date imposée — MVP d'abord, lancement si validé | Totalement flexible |
| **Budget** | Zéro budget initial. Prêt à investir les frais Play Store si le produit est validé | Flexible selon traction |
| **Équipe** | Solo (Fitz + Claude Code) + amis ponctuels. GitHub dès le départ | Peut évoluer |
| **Technique** | Web app + mobile natif obligatoires. Architecture cross-platform dès le départ | Stack à définir à l'étape Tech Stack |
| **Brand** | Aucune contrainte fixe. Direction : inspirer confiance et envie d'utiliser | Totalement ouvert |

## Notes clés
- Architecture doit être pensée pour un dev solo, pas une équipe
- Approche lean : développer → utiliser → retours d'amis → valider → mettre en ligne
- GitHub obligatoire dès le début
