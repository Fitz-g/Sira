## Composants & Object IDs

#### `OBJ-09-1` — Header
| Propriété | Valeur |
|-----------|--------|
| **Type** | Titre `h1` + sélecteur mois |
| **Token** | `heading-md` (20px), poids 600 |

#### `OBJ-09-2` — Vue globale
| Propriété | Valeur |
|-----------|--------|
| **Type** | Card résumé |
| **Contenu** | Revenus / Dépenses totales / Solde restant estimé |
| **Style** | 3 colonnes, valeurs en FCFA |

#### `OBJ-09-3` — Barres budget par catégorie
| Propriété | Valeur |
|-----------|--------|
| **Type** | Liste de progress bars |
| **Contenu** | Catégorie + montant dépensé / budget alloué + pourcentage |
| **Couleur** | Verte si < 80%, orange si 80-100%, rouge si > 100% |

#### `OBJ-09-4` — Card alerte dépassement *(conditionnelle)*
| Propriété | Valeur |
|-----------|--------|
| **Type** | Card warning |
| **Contenu** | "Tu as dépassé ton budget [catégorie] de [montant] FCFA" |
| **Visibilité** | Uniquement si au moins une catégorie dépassée |

#### `OBJ-09-5` — Bouton "Ajuster mon budget"
| Propriété | Valeur |
|-----------|--------|
| **Type** | Button secondaire |
| **Token** | `heading-xs` (16px), poids 600 |
| **Style** | Bordure couleur principale |
